# CCTVScan UI Brief

Quasar/Vue operator console; preserve existing Public Sans, yellow accent and neutral tokens.

## Learned constraints
- Compact tables, ten rows by default, visible pagination and row-size selection. Avoid oversized whitespace and empty inspector columns.
- No repetitive warnings, legalistic lectures, or explanatory sidebars. Put operational details where needed; preserve genuine errors and existing scan behavior.
- Favor direct, fast changes. Only necessary verification; no sprawling test/review ceremony for copy and density fixes.
